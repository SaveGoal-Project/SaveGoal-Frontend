# UI Components

This directory contains Shadcn/UI components.

## Installation

To add a new Shadcn component, run:

```bash
npx shadcn@latest add [component-name]
```

Components will be automatically added to this directory.

## Usage

```tsx
import { Button } from "@/src/components/ui/button";
import { Card } from "@/src/components/ui/card";
```

## Available Components

Install components as needed. Common ones for SaveGoal:

- `button` - Primary action buttons
- `card` - Product cards, goal cards
- `input` - Form inputs
- `dialog` - Modals and popups
- `toast` - Notifications
- `table` - Data tables
- `badge` - Status indicators
- `progress` - Savings goal progress bars
- `avatar` - User avatars
- `select` - Dropdowns
- `form` - Form components

See [SHADCN_SETUP.md](../../../SHADCN_SETUP.md) for full setup instructions.
